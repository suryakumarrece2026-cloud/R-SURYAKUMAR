# R-SURYAKUMAR
Arduino closed-loop liquid cooling and thermal energy recovery prototype using DS18B20 and 5V relay.
# Automated Thermal Energy Recovery & Liquid Cooling System

Closed-loop thermal management prototype using:
- **Arduino Uno**
- **DS18B20** digital temperature sensor (Pin 2, with 4.7kΩ pull-up resistor)
- **5V Relay Module** (Pin 7)
- **9V Water Pump** & **10W Power Resistor** heat load

Triggers liquid circulation when temperature reaches **30°C** or higher.
